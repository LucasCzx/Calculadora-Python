# Calculadora em Python

Uma calculadora simples desenvolvida em Python para praticar lógica de programação.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão

## Como executar

1. Instale o Python.
2. Abra a pasta do projeto no VS Code.
3. Execute o arquivo `calculadora.py`.

## Tecnologias

- Python 3
